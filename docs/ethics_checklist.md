# Ethics and data checklist (paper Sec. VII)

Complete before every recording day.

- [ ] Every participant has signed the consent form; withdrawal was explained.
- [ ] Participants are recorded under codes (P01, P02, ...) only. No video.
- [ ] Raw recordings go to access-controlled college storage, never to this repository.
- [ ] Monitor capture is header-only (`tcpdump -s 128`); no payloads stored.
- [ ] All traffic, including active-sensing tests, targets project-owned devices only.
- [ ] AP channel and power are within CST (Saudi Arabia) limits; DFS enabled.
- [ ] No jamming signal is transmitted; jamming exists in simulation only.
- [ ] Only consented, de-identified data is prepared for public release.
